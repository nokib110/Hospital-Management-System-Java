# Hospital & Patient Management System 🏥

A Java-based Hospital & Patient Management System designed to streamline essential hospital operations, including patient records, doctor management, appointments, authentication, and billing.

## 📌 Project Overview

The **Hospital & Patient Management System** is a desktop-based Java application developed to manage common hospital operations through a user-friendly graphical interface.

The project demonstrates core **Object-Oriented Programming (OOP)** concepts, including:

* Inheritance
* Polymorphism
* Encapsulation

The application uses **Java Swing** to provide the graphical user interface.

## ✨ Features

### 🔐 Authentication

* Secure admin login system.
* Restricts access to authorized users.

### 🧑‍⚕️ Patient Management

* Add new patient records.
* Update existing patient information.
* Search patient records.
* Delete patient records.

### 👨‍⚕️ Doctor Management

* Add and manage doctor information.
* Store doctor specializations.
* Manage doctor details within the system.

### 📅 Appointment Management

* Book appointments between doctors and patients.
* Manage doctor-patient appointment information.

### 💳 Smart Billing

* Automatically calculates patient bills based on disease type.
* Different diseases have different treatment costs.
* For example, major procedures such as heart surgery have higher costs than treatments for common illnesses such as flu.

## 🛠️ Technologies Used

* **Java**
* **Java Swing**
* **Object-Oriented Programming (OOP)**

## 🧠 OOP Concepts Demonstrated

The project applies several fundamental OOP principles:

* **Inheritance** — Reuse and extend common properties and behaviors between classes.
* **Polymorphism** — Allow objects to behave differently through common interfaces or inherited methods.
* **Encapsulation** — Protect and organize data through classes and controlled access.

## 🚀 How to Run

### Prerequisites

Make sure you have:

* Java Development Kit (JDK)
* IntelliJ IDEA, Eclipse, or another Java IDE

### Steps

1. Clone or download the repository.

2. Open the project in **IntelliJ IDEA** or **Eclipse**.

3. Make sure all Java source files are included in the project.

4. Locate:

```text
HospitalGUI.java
```

5. Run `HospitalGUI.java`.
